Syntax

a) expression doesn't modify variable

i.e this doesn't work properly: 

#include <stdio.h>
void adv(int *p) {
	*p + 1;
}

int main() {
	int l[] = {1,4,9,16,25};
	int *a = l;
	
	adv(a);
	printf("%d\n", *a);
}

will give you 1 because you only advanced *p by 1 in adv() and didn't assign that pointer to the outer function.

The fix: 

#include <stdio.h>
void adv(int *p) {
	*p = *p + 1;
}

int main() {
	int l[] = {1,4,9,16,25};
	int *a = l;
	
	adv(a);
	printf("%d\n", *a);
}

because *p = *p + 1 is assigning pointer p advanced by 1 to the pointer p in the outer function
